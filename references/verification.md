# 独立验收参考

验收针对**最终交付的 HTML 在真实浏览器中的渲染结果**。静态分析只能证明代码形状，不能证明关系、画面和时序成立。

## 1. 先写验收矩阵

开始编码前，把场景的强制约束转成可观察断言。每条至少记录：证据来源、采样时刻/画幅、容差、结果。不要只写“看起来正常”。

| 类别 | 本场景要检查什么 | 证据来源 | 采样 | 容差/结果 |
| --- | --- | --- | --- | --- |
| 语义结构 | 必要部件、开口/实心、连接、包含、遮挡 | DOM 层级 + 截图 | 代表帧 | 全部存在 |
| 关系误差 | 触手根与伞缘、灯球在伞内、装饰不越界 | 实际路径点/变换/填充测试 | 全周期 24+ 点、极值、事件 | 见下 |
| 运动可行性 | 可达极值、刚性尺寸、非预期形变 | 实际 DOM 矩阵/路径 | 最大/最小姿态 | 约束内 |
| 时间连续性 | 循环边界、关键帧、事件切换 | 实际属性/截图采样 | P−ε、P、P+ε + 均匀 24 点 | 见下 |
| 展示完整性 | 三画幅主体完整、控制不遮主体 | `getBoundingClientRect` + 截图 | 每个画幅 ≥2 相位 | 全在舞台内 |
| 交互一致性 | 暂停/继续、键盘、后台恢复、减少动态 | 浏览器操作记录 | 至少一次完整切换 | 全同步 |

容差必须结合场景尺度定义，不能为了“通过”过宽。建议起点：

- 连接/接触误差：≤ 0.5% 主体高度，且 ≤ 2 CSS px；需求有更严格约定时用更严格值。
- 穿插/包含失败：0 容差；一旦越界就是失败，除非该时刻本就设计为解除该关系。
- 刚性尺寸变化：相对变化 ≤ 1e-6。
- 循环边界：在相邻帧步长 `δ=16.7ms` 下，`P−δ → P` 的位置变化 ≤ `max(1px, 1.5 × 0→δ 的内部变化)`；透明度变化 ≤ `max(0.02, 2 × 内部变化)`；用同一组点计算边界的有限差分速度，前后两段速度向量的不匹配 ≤ `max(1px, 0.75 × 边界速度幅值)`。端点相同可能是 `renderAt` 归一化造成的构造性相等，不能单独作为通过证据。
- 后台恢复：不出现隐藏时长对应的位移/相位追赶。
- 主体可见性：最终屏幕包围盒全部在舞台矩形内，保留 ≥ `max(2% 舞台短边, 8px)` 的安全边距；暂停控件不与主体包围盒相交。
- 三画幅：390×844、844×390、1440×900 均检查；每个画幅至少 2 个动作相位，若有紧密接触/遮挡再增加关键相位。

## 2. 验证分层

### A. 交付与静态结构

- 只有一个 HTML 文件；无外部脚本、样式、字体、图片、iframe、媒体、`fetch`/XHR/动态 import。
- `data:` 和文档内 `#fragment` 引用是内联的，可放行；相对路径、`file://` 同级文件和任何网络地址都算外部依赖。
- 检查所有资源型属性，而不只是 http：`<script src>`、`<link rel=stylesheet/preload/icon>`、`<img src/srcset>`、SVG `<image href>`、`<use href>`、`@font-face src:url(...)`、CSS `url(...)`、`poster` 等。`url(#gradient)` 合法。
- 浏览器实际加载也应作为证据：监听资源请求并读取 `performance.getEntriesByType("resource")`，只允许主文档和 `data:`/`blob:` 资源。
- 有正确的 viewport、HTML 语言、页面标题。
- 内联 SVG 根节点有 `role="img"`、`aria-labelledby`，`<title>`/`<desc>` 非空且 ID 正确。
- 暂停/继续使用真实 `<button>`，有可读文字、键盘可操作；短横屏也不能从可访问树中移除状态 live region。
- 有 `prefers-reduced-motion` 分支和页面可见性处理。
- 场景运动来自同一 JavaScript 时钟；本项目不使用 SMIL 或场景 CSS 动画作为交付时基。

### B. 浏览器几何

用浏览器读取最终 DOM：

```js
// 实际屏幕边界
const subject = [...document.querySelectorAll('[data-subject]')]
  .map(el => el.getBoundingClientRect());
const stage = document.querySelector('[data-stage]').getBoundingClientRect();

// 实际路径点
const path = document.querySelector('#tentacle-0');
const p = path.getPointAtLength(0);
const m = path.getScreenCTM();
const screen = new DOMPoint(p.x, p.y).matrixTransform(m);

// 包含测试（使用浏览器自己的几何实现）
const inside = container.isPointInFill(localPoint);

// 最近距离：不要重算生成公式，从目标路径采样后求最近点
```

对于连接关系，验证实际两个几何对象在最终坐标中的间距。对于包含，验证点/关键轮廓确实在填充内。对于遮挡，检查绘制顺序并看截图确认，上下文中的“存在 group”不是充分证据。

### C. 时间采样

同时使用均匀采样和关键事件采样：

- **均匀**：在主周期内至少 24 个等距时刻；若动作快或约束紧，增加到 48–120 个。
- **极值**：每个振荡的峰、谷、过零点；机械行程的两端。
- **事件**：接触建立/解除、遮挡切换、粒子回绕、层序改变。
- **循环边界**：`P−2ε`、`P−ε`、`P`、`P+ε`，并和内部相邻帧比较。至少检查 3 组边界对。
- 发现可疑区间时加密采样；不要只取首帧、末帧和少数整数秒。

每个采样时刻至少记录：主体屏幕包围盒、关键连接点距离、包含测试、实际路径点范围、透明度和按钮/时钟状态。把不可见但会重置的对象的视觉等价条件写成断言。

### D. 交互验证

1. 默认状态：动画在播放，按钮动作文字与 `data-playing` 一致，页面无报错。若页面用 `aria-pressed` 代替，应确保标签稳定且状态语义不冲突。
2. 暂停：点击或键盘激活后，间隔 ≥400 ms 取两份场景 SVG/属性快照，应完全一致；所有场景动画都停。提供审计钩子时，冻结期间模拟时钟也不得推进。
3. 继续：恢复后等待 ≥200 ms，场景状态应变化；用审计钩子读取暂停相位与恢复后前两帧相位，要求相位模周期向前推进，且增量与恢复后的真实耗时相差 ≤250 ms，不能回到 0 或等待超过阈值。裸 DOM“发生了变化”不能证明没有重播。
4. 减少动态：以 `prefers-reduced-motion: reduce` 启动，必须默认停在代表帧且不自行推进；同时检查 `document.getAnimations()` 中没有仍在场景子树内运行的动画。控件必须可操作；用户显式点击后应能启动动画。
5. 后台恢复：模拟/实际切到隐藏再恢复，检查不追赶隐藏时长、无 NaN/异常、画面仍正常。至少做 DOM 层模拟；无法做真实生命周期时明确标注。
6. 三画幅：设置精确视口尺寸，检查 `scrollWidth === innerWidth`、主体全部可见、按钮可点击且不遮主体。

### E. 视觉检查

程序检查通过不等于观感正确。必须亲自看三张最终截图，至少在两个相位检查：

- 主体轮廓和必要特征是否可辨认；
- 前后层级、遮挡、透明度、接触是否合理；
- 标题、控制条和背景是否压主体；
- 构图是否平衡、是否有意外裁切、突兀空白或比例失衡；
- 减少动态代表帧是否仍是一张完整好看的画面。

## 3. 使用项目内审计脚本

页面需要提供这些最小契约（详见 `SKILL.md` 的“审计接口约定”）：`[data-stage]`（可选）、`[data-scene]`、`[data-subject]`、`[data-animated]`、`[data-motion-toggle]`。建议只在 `?audit=1` 时暴露 `window.__svgSceneAudit`，并把 `periodMs`、`renderAt`、`getState` 委托给生产渲染路径和真实时钟状态。

```bash
node .agents/skills/svg-motion-scene/scripts/audit_scene.mjs path/to/scene.html --shots .audit
```

脚本解析和运行交付页面，自动检查：

- 外部资源（含相对路径、SVG `href`、CSS `url()`、`file://` 实际请求）、viewport、标题/说明、暂停控件等交付契约；
- 三种视口下的主体包围盒、按钮遮挡、动态安全边距和页面溢出；
- 播放→暂停→继续、键盘、减少动态；提供审计钩子时检查暂停相位冻结与恢复相位连续；
- 页面提供 `window.__svgSceneAudit` 时，从实际 SVG 几何检查循环边界位置、透明度和有限差分速度；端点相等只作参考；
- 通用脚本不会验证场景语义、连接、包含、遮挡和物理约束，这些仍需用下面的示例方式另写断言。

脚本依赖开发期的 Playwright；交付的 HTML 本身不能依赖它。若本机没有 Playwright，脚本会明确失败并给出安装方式，不会把未运行当作通过。

对 `starter.html` 的示例关系测试（不是通用规则）：

```bash
node .agents/skills/svg-motion-scene/tests/starter-relations.mjs
```

它从实际路径采样触手根部到伞缘的距离、灯球周围点是否在伞内、吊点/伞顶、刚性尺寸等。为新场景编写类似测试，不要直接复用 starter 的节点选择器。

脚本**不能**验证：

- 场景语义、部件是否真的存在、连接方向是否合理；
- 物理上正确的接触/遮挡设计；
- 自定容差的几何关系；
- 真实浏览器标签页生命周期（只做 DOM 触发时会在输出中标注）。

因此还要按场景另写断言。可以在审计时使用页面提供的只读钩子，但不要只验证钩子返回的“正确参数”；要从 DOM 路径、变换、包围盒和截图读取结果。

## 4. 建议的起始几何测试

以下只是模板，不代替具体场景推导：

```js
// 连接：触手根部到伞缘路径的最近距离
const bell = document.querySelector('[data-part="bell"]');
const tentacle = document.querySelector('[data-part="tentacle-0"]');
const root = pointOnPath(tentacle, 0);           // 实际屏幕坐标
const rimDist = distanceToPathScreen(bell, root); // 采样伞路径实际点
if (rimDist > TOL_PX) fail('tentacle root detached', rimDist);

// 包含：灯球中心在伞内部
const lantern = document.querySelector('[data-part="lantern"]');
const bellLocal = toLocal(bell, centerOf(lantern));
if (!bell.isPointInFill(bellLocal)) fail('lantern escaped bell');

// 刚性：灯球半径不变
compare(measuredRadii, { tolerance: 1e-6 });
```

对周期采样，记录实际 DOM 点或包围盒签名，避免“直接调用生成函数得到相同结果”的循环论证。

## 5. 循环与后台恢复的判定

- **状态连续**：循环边界的可见几何变化与正常相邻帧同量级。允许“位置不同但视觉等价”（例如透明度 0 的粒子重置），但必须验证两端透明度/遮罩确实使画面等价；数值等价阈值不要宽到掩盖肉眼可见的 1–2% 透明度变化，脚本使用 1/255 作为不可见下限。
- **速度连续**：连续运动在边界两侧没有方向突跳。用边界前后各一帧的有限差分速度向量比较，而不仅是位置变化量。若是设计事件（弹跳、撞击），必须能解释事件本身并在截图/数值中体现。
- **独立节奏**：不同部件可有不同周期，但主周期必须闭合并通过同一状态函数渲染。
- **后台恢复**：记录隐藏前相位、恢复后立即相位、下一帧相位。隐藏期间不应注入时间；恢复后相位增量应接近一帧，而不是隐藏时长。
- **真实浏览器限制**：如果只模拟了 `visibilitychange` DOM 事件，应写明“DOM 模拟”，不要宣称完成了真实标签页挂起测试。
